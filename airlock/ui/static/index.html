AirLock

Send a file with light, safely

Alice sends Bob a file without Wi-Fi, Bluetooth or cables: her phone plays the file as QR codes, and Bob's laptop camera reads them. Anyone in the room can film that screen, so the file is locked so that only Bob can open it, and sealed so that Bob knows it came from Alice.

🔒

Lock

The file is encrypted with a brand-new key that only Bob's laptop can recreate.

✍️

Seal

Alice signs it, so any change to it, or a fake sender, is detected.

▦

Show

The locked file is cut into small pieces, each shown as one QR code in a looping video.

📷

Check

Bob's laptop checks the seal, the date and that this transfer is new, then unlocks every piece.

✅

Confirm

Both screens show the same short code. Only if a person confirms it is the file saved.

What an attacker can do, and why it fails

Film the screen
Gets only scrambled data; the key never appears on screen.
Pretend to be Alice
Can't make Alice's signature; Bob only trusts keys checked in person.
Change the data
Every piece carries a tamper seal; changed pieces are thrown away.
Replay an old video
Bob remembers what he already received, and old videos expire.
Stop it halfway
Nothing is saved until the whole file has been checked.

The technical names (for questions)

Lock
X25519 key exchange + AES-256-GCM encryption
Seal
Ed25519 digital signature
Tamper seal per piece
GCM authentication tag (header included)
Whole-file check
SHA-256 fingerprint, signed by Alice
Short code
32-bit verification code derived from the session key
