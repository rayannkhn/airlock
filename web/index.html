      How AirLock works

      1. Pair once. Two devices scan each other's code and you compare fingerprints. Now each knows the other's public keys.
      2. Lock. The file is encrypted (AES-256-GCM) with a one-time key that only the receiver's device can recreate (X25519).
      3. Seal. The sender signs it (Ed25519), so nobody can change it or pretend to be the sender.
      4. Show. The locked file is cut into small pieces, and each piece is one QR code on a looping screen.
      5. Check. The receiver checks the seal, that the transfer is fresh, and that it has never been received before (no replays). It then unlocks each piece and checks the whole file's fingerprint (SHA-256).
      6. Confirm. Both screens show the same short code. Only after a person confirms it is the file handed over.

      Why it's safe to show on screen

      Anyone can film the codes, but all they get is locked data. The key never appears on screen, and changed or replayed codes are rejected.

      After the first visit the app works with no internet at all, and its security policy blocks it from contacting any server.
